Dual maps

Dual maps is a web application that allows you to synchronize views of different map types side by side.

Compare satellite views with 3D buildings layer, railroads with Bing maps, typography and air traffic map. You decide!

Keyboard shortcuts

  • 1 - Toggle axis displaying
  • 2 - Import URL from Google Maps

Built with:

  • The best library for dealing with Open Street Maps - Leaflet.
  • Leaflet.GeoSearch
  • Leaflet Linear Measurement Plugin
  • OSM Buildings
  • Wikimapia
  • Google Maps
  • Bing maps
  • ADSB Exchange
  • Vite
